# 디지털 마피아 M2 정적 클릭 프로토타입

## 실행

`index.html`을 브라우저에서 열거나 정적 웹 서버에 폴더 전체를 올립니다.

- 시연 세션 코드: `2026`
- 학생 화면: `index.html`
- 교사 화면: `teacher.html`

## 포함 기능

- 팀 번호·별칭 입장
- 역할 카드 5종
- 사건 관찰과 첫 판단
- 검증 질문 작성
- 3개 단서 라운드
- 증거 2개 이상 선택
- 최종 판정·조작 수법·대응문
- 진실 공개·근거 점수·개인 성찰
- 브라우저 임시 저장과 새로고침 복원
- 교사용 진행판 정적 시연

## M2 제한

- 실제 세션 생성과 다중 사용자 동기화는 없습니다.
- Google Sheets 저장은 없습니다.
- 교사 화면의 팀 현황은 시연 데이터입니다.
- 실제 25명 동시접속 검증 대상이 아닙니다.

이 제한은 M3 Google Apps Script 최소 기능판에서 구현·검증합니다.
